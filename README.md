# ETL Project – Data Cleaning & KPI Dashboard

## Overview
This project demonstrates a complete ETL workflow including data cleaning, transformation, and KPI visualization.

The dataset was processed using SQL and then transformed into business-ready insights through an Excel dashboard.

---

## ETL Process
The following steps were applied:

- Data ingestion from CSV
- Data cleaning and normalization
- Handling duplicates and formatting issues
- Data transformation using SQL queries

All SQL scripts are available in this repository.

---

## Dashboard

The final dashboard was built in Excel using cleaned and structured data from the ETL process.

- The Excel file contains KPI calculations and pivot tables
- Screenshots provide a quick visualization of the results

Files:
- `/excel/etl_kpi_dashboard.xlsx`
- `/screenshots/dashboard_overview.jpeg`

---

## Key KPIs

- Total Employees
- Active Employees
- Average Salary
- Average Tenure
- Headcount by Area
- Work Mode Distribution
- Age Distribution
- Data Quality (Null Rate & Email Validation)
